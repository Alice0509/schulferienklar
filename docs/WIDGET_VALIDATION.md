# Schulferienklar Widget Validation

Updated: 2026-08-03

## Purpose

The Nächste-Schulferien Widget is a free distribution experiment for
Schulferienklar.

The Widget remains free to use without prior approval, payment or an account.

Current traffic and usage are not yet high enough to justify commercial
outreach, paid infrastructure or professional service offers.

## Current observation phase

The observation period remains open-ended until the Widget receives meaningful
organic traffic and real external usage.

Current signals are:

- Widget code copies
- voluntarily submitted websites
- confirmed external installations
- referrals from embedded Widget attribution links

There is currently no fixed 90-day commercial validation deadline.

## Website registration

Website operators may voluntarily submit a website after embedding the Widget.

The registration email asks for:

- website or organisation name
- public website URL
- exact page containing the Widget
- website category
- selected Bundesland and Widget configuration
- explicit permission to publish the website name and link

Registration is optional and does not affect free Widget use.

## Review process

A submitted website is never published automatically.

Before publication:

1. Open the submitted page.
2. Confirm that the Schulferienklar Widget is actively embedded.
3. Check that the website is relevant and appropriate.
4. Confirm that publication permission was provided.
5. Approve or reject the submission manually.

Publication does not represent an official partnership, endorsement or
recommendation by Schulferienklar.

## Public showcase

Do not create an empty public showcase page.

After approximately 3 confirmed installations, consider creating:

- `/widget-im-einsatz.html`

Initial public entries should contain only:

- verified website or organisation name
- website category
- Bundesland
- verification date
- external website link

Do not initially publish user-supplied logos, images or unrestricted
descriptions.

Public links should use:

- `rel="ugc nofollow noopener noreferrer"`

## Signals collected

The public Widget builder may record these actions only after analytics consent:

- `copy-widget-code`
- `register-widget-website`

The embedded Widget itself contains no analytics scripts, cookies, advertising
or behavioural tracking.

Its Schulferienklar attribution link uses aggregate UTM referral parameters.

## Commercial features currently paused

The public Widget page does not currently offer:

- custom Widget development
- paid Widget plans
- paid APIs
- custom calendar or data feeds
- pricing or commercial contracts
- direct sales outreach

These topics may be reconsidered only after meaningful organic demand exists
and the appropriate business setup is in place.
