# Berlin one-off statutory holiday, 17 June 2028

Base: cfe45d87a81d18d3eff92bcc32cc3f7e53b2d715 (PR #288).

## Confirmed defect

Berlin's one-off statutory holiday on 17 June 2028 was missing from the
public-holiday dataset. The official education department's holiday page and
Berlin's gazette confirm it. The Fourth Act amending the Sundays and Holidays
Act of 10 July 2024 adds the anniversary of the uprising of 17 June 1953;
the provision is removed on 18 June 2028.

This discovery arose during the continuing state-source audit. It is not
identified as the cause of the AdSense low-value-content rejection, and the
primary-source review of all 16 states is not yet complete.

## Change

- Add the holiday only to Berlin's 2028 generation rule and data copies.
- Attach the official source and 12 October 2026 verification date to this
  individual event. Existing events and dataset source dates remain unchanged.
- Retain event-specific verification dates in yearly ICS and subscriptions.
- Update the Berlin event counts, annual calendar, yearly ICS and subscription.
- Explain the limited verification scope on the data-sources page.
- PDF and static API files are generated by the existing build workflow.
- Git attributes preserve required ICS CRLF endings and avoid treating the
  carriage return as trailing whitespace in diffs.
- The holiday falls on Saturday; it does not add a free weekday to the existing
  Monday–Friday vacation optimizer assumptions.

## Validation

- 46 tests passed, including regeneration in an isolated directory and checks
  that the one-off event does not appear in other states or years.
- ESLint, data, SEO, annual-calendar, API, subscription and regional-parity
  validations and Vite build passed on the final files.
- The checked build passed before the final event-specific metadata refinement;
  relevant generators and validators were rerun after that refinement.
- All 80 PDFs generated. Berlin 2028 PDF was rendered and visually checked;
  17 June appears with the statutory-holiday highlight.
- API public-holiday and combined-calendar outputs include one correctly sourced
  event. Both ICS outputs use DTSTART 20280617 and exclusive DTEND 20280618.
- The other 15 subscription feeds match the base byte-for-byte.
- Mobile and desktop browser checks cover the annual calendar and Berlin 2028
  interactive calendar loading. Generation-only date changes were excluded.
